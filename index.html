01Agents

Every brand has a manager. One window sits over all of them.

A manager is an AI agent that lives in its brand's repository. It knows the brand's website, mailbox, calendar, leads and open questions, and it writes down what it learns. Above them, a manager of managers answers across all brands and opens the right one when there is work to do.

One identity per agent.

Each manager works under its brand's own account and is refused on any other. Nothing leaks between brands.

b
Memory is written, not assumed.

Every decision, correction and run goes into dated notes in the repository, so the next session starts where the last one ended.

c
The agent drafts. A person sends.

Replies to doctors and patients are prepared in full and wait for a human to press the button.

02Engine

Clinical software from configuration, not code.

Our engine is a no-code framework for standardised healthcare applications. The data model, the terminology and the behaviour are already in the system and shared by everyone who uses it. A new application is a description of how to use them, written in JSON.
